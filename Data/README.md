# Data

This folder contains the datasets used for the Tottenham Hotspur Transfer Impact Analysis.

## Planned datasets

### 1. transfers.csv
Information about Tottenham Hotspur player signings.

### 2. team_performance.csv
Tottenham's season-level Premier League performance.

### 3. player_performance.csv
Performance statistics for Tottenham players.

## Data sources

- Transfermarkt — transfer information
- FBref — team and player performance statistics

The datasets will be cleaned and transformed before analysis.
